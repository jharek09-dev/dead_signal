# Localization Plan

Status: ✅ **v1.1 available** → **[`LOCALIZATION.md`](LOCALIZATION.md)**

The plan for making Dead Signal translatable: **string externalization** as the critical path, the
key-catalog architecture, target-language tiers, culturalization traps (the `143` motif, the
`KIM → ELLIE` flip, Ellie's lowercase register), font/CJK coverage, the pipeline (pseudo-loc, ICU,
TMS), and LQA.
